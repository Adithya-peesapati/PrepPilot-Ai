# 🚀 PrepPilot AI

**Learn Smarter. Interview Better. Succeed Faster.**

PrepPilot AI is an AI-powered personalized learning and interview preparation platform developed for **InnovaHack Chapter 1 – Generative AI (Problem Statement 2)**.

It helps students prepare effectively for exams and interviews by generating personalized practice questions, evaluating answers using AI, and providing detailed feedback with adaptive learning recommendations.

---

## 📌 Problem Statement

Students often rely on generic learning resources that do not adapt to their individual strengths, weaknesses, or learning pace. This results in inefficient preparation and a lack of personalized feedback.

PrepPilot AI solves this problem using Generative AI by providing customized practice tests, intelligent answer evaluation, and performance analytics.

---

## ✨ Features

- 👤 User Profile Creation
- 🎯 Preparation Goal Selection
  - Semester Exams
  - Placement Interviews
  - Coding Interviews
  - Aptitude Tests
  - HR Interviews
- 📚 Topic-wise Practice Tests
- 📊 Difficulty Levels
  - Easy – 20 Questions
  - Medium – 15 Questions
  - Hard – 10 Questions
- 🤖 AI Question Generation
- 📝 AI Answer Evaluation
- 📈 Performance Dashboard
- 💡 Personalized Learning Recommendations
- 🔐 Secure User Authentication

## ⚙️ How It Works

1. User signs up or logs in.
2. Creates a personalized profile.
3. Selects a preparation goal.
4. Chooses a topic.
5. Selects a difficulty level.
6. AI generates personalized questions.
7. User answers the questions.
8. AI evaluates the responses.
9. Dashboard displays performance and recommendations.
